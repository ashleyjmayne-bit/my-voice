# My Voice — Optional Feature Requests

## 1. Public Alexa+ hackathon sandbox
**Priority:** Critical

Provide a limited public Alexa+ sandbox or browser simulator for hackathon participants.

**Why it matters:**  
A sandbox would let developers validate interaction patterns against the real platform instead of relying entirely on a custom simulation when production add-on tooling is gated.

---

## 2. Alexa+ simulation reference guide
**Priority:** Important

Publish a short design and compliance guide specifically for the simulated Alexa+ submission path.

**Why it matters:**  
Participants need a quick answer to practical questions such as whether voice is required, whether a custom UI is acceptable, how much Alexa+ resemblance is expected, and what the demo must show.

---

## 3. Accessibility and consent reference patterns
**Priority:** Nice-to-have

Provide sample Alexa+ patterns for explicit consent, sensitive-action confirmation, accessible multimodal fallback, and preserving user wording separately from agent interpretation.

**Why it matters:**  
These patterns would help developers building for older people, disabled users, and other users who may be harmed by hidden automation or ambiguous consent.
